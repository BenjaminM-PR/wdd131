Recording Records

Site Name

Recording Records --- I like this name by using 2 times the word "record", one by the verb of recording something (on this case the user collection or wishlist)

Site Purpose

The main objective of the site is to create a personal tracker of a vinyl collection or wishlist by inserting the name, a link of a picture, the release year, and an estimated price, besides a wishlist and my personal collection

scenarios

  • how would my collection look like on a list instead of on a shelf?
  • how can i easily organize my wishlist on a more graphical way?
